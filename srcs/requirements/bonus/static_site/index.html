> INSPECT ARCHITECTURAL PARADOX (WHY CONTAINERS ≠ VMs)

Unlike nested Virtual Machines—where each dream level requires booting an entire guest OS kernel—Docker containers share the host Linux kernel using namespaces and cgroups. Each level remains isolated while keeping startup time under one second.
